Comment jouer ?

Révéler

Clique sur une case. Un nombre indique les mines voisines ; une case vide ouvre automatiquement toute sa zone.

Marquer

Clic droit sur ordinateur ou active le mode drapeau sur écran tactile.

Premier clic

Le premier clic et les cases voisines sont toujours protégés.

Gagner

Révèle toutes les cases sans mine. Poser tous les drapeaux n’est pas obligatoire.
